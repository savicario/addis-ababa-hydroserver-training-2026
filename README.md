# Training in HydroServer

**Workshop Piloting Interoperable Hydrometeorological Data Systems for Multi-Hazard Early Warning Systems**

This repository contains the code and data for the workshop to be held in Addis Ababa, Ethiopia, on September 14–17, 2026, for the hydrological services of Uganda, Rwanda, Ethiopia, and Kenya.

Each country folder contains subfolders for the exercises. Each exercise folder includes the code and sample data tailored to that specific country.

- **Exercise 1: Loading Sensor Data for a Monitoring Station.** See the [Presentation](https://www.canva.com/design/DAHRQLP5gXM/pqTYE9o6zTy-eI5wYU9MmA/edit) for instructions. We will go through the presentation and complete the exercise together during the workshop. In this exercise, you will create your own workspace, monitoring sites, datastreams, and observations in HydroServer using sample data from monitoring stations in your country.
